# Original brand media

No original image/video binaries are bundled here. The delivered preview uses
source URLs recorded in ../asset-manifest.json and needs internet access.

The local_file values in that manifest reserve future paths; they do not prove
these files exist. ../fetch_assets.py can attempt original image retrieval on an
internet-enabled machine. Full videos, approved logo sources and a compatible
export of the HEIC reference remain production asset tasks.
