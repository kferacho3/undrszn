# Members collection preview photography

These assets are web-optimized derivatives of the 13 actual images supplied in **Luxury Idea.zip**. They are concept previews, not confirmed commerce product records. Display titles describe the images; they are not approved product names.

## Image processing

- The supplied originals remain unchanged outside this repository.
- Files were re-encoded as WebP at quality 86, using 480 px, 800 px and up to 1200 px widths.
- The maximum width never exceeds the original image width. No file was upscaled.
- Each derivative preserves the full image contents and original aspect ratio (subject only to integer pixel rounding). No source image was cropped, retouched or mirrored.
- `IMG_6857.PNG` includes black screenshot bars. Its derivatives deliberately retain those bars. The corresponding record in `src/data/members.ts` has `screenshotCrop: true` so the presentation can conceal the bars with CSS while the complete image remains available through its source URL.
- Source lettering and emblems are retained as supplied.

The typed manifest is `src/data/members.ts`. It provides intrinsic dimensions, responsive `srcSet` values, descriptive alt text, fit guidance and semantic IDs for all images.
